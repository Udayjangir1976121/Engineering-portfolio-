# Engineering World — Personal Portfolio

A React + Vite portfolio for Anshu, an Electronics & Computer Engineering student at MBM University, Jodhpur.

The visual language is colour-rich 8-bit / block-world inspired, while the content is structured around real engineering work across embedded systems, robotics, electronics and simulation.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Where to edit your portfolio

- `src/data/projects.js` — project titles, descriptions, technologies, results and the details shown on each project page.
- `src/components/About.jsx` — education, current direction and experience text.
- `src/components/Contact.jsx` — GitHub, LinkedIn and email links.
- `src/components/Hero.jsx` — homepage introduction and headline stats.
- `src/styles.css` — visual system and responsive layout.

## Current project set

The portfolio now focuses on six relevant pieces of work:

1. Battery Lab — simulation-first BMS work.
2. Holo Battalion — holonomic robotics, ROS2, control and perception.
3. Mapping Robot — low-cost mapping platform in development.
4. 4-DOF Robotic Arm — physical embedded robotics build.
5. 15 kg Battlebot — electro-mechanical robotics build.
6. ESP32 Lab — ESP-IDF, ESP32-CAM and embedded experiments.

Railway Signalling & Telecommunications work is presented separately in the About section as industry experience, not as a project.
